# E-commerce Product & Review Analysis

An end-to-end analytics project: scrape, clean, store, analyze and visualize product data from an e-commerce site.

## Business question
Which categories, price points and ratings stand out across the site's products?

## Tools
Python (BeautifulSoup, Pandas), MySQL, SQL, Power BI

## What I did
1. Scraped product names, prices, ratings, availability, categories and URLs with Python.
2. Cleaned and transformed the data with Pandas and loaded it into MySQL.
3. Wrote SQL queries on pricing, ratings, availability and category trends.
4. Built an interactive Power BI dashboard with KPIs, slicers and an insights page.
